# Marca — Ateliê Sacro

Monograma **A + S** sob um nicho ogival, com cruz no ápice.
O travessão do **A** é prolongado para ler como barra de cruz; o **S** atravessa
o vão do A em traço contínuo, entrelaçando as duas letras.

## Cores

| Uso        | Hex       | Token do site |
|------------|-----------|---------------|
| Dourado    | `#8C6239` | `--gilt`      |
| Tinta      | `#1C1A17` | `--tinta`     |
| Cal (fundo)| `#F7F4EE` | `--cal`       |
| Sobre gilt | `#FFFDF8` | `--sobre-gilt`|

Favicon usa `#C79A63` (dourado clareado) sobre tinta, para segurar contraste a 16px.

## Arquivos

- `icone.svg` — símbolo isolado (nicho + monograma). Use a partir de ~28px.
- `logo-horizontal.svg` — lockup para o topo do site.
- `logo-empilhada.svg` — vertical, para embalagem e etiqueta.
- `logo-horizontal-escuro.svg` — sobre fundo escuro.
- `*-preto / -branco / -dourado` — monocromáticos (gravação, carimbo, 1 cor).
- `favicon.svg` — desenho simplificado, sem o nicho, para 16–48px.

## Área de respiro

Deixe em volta uma margem igual à altura da cruz do ápice (~15% da altura do símbolo).

## Atenção

Os lockups com texto usam `<text>` + Cormorant Garamond via Google Fonts.
Renderiza certo no navegador; para **impressão ou Illustrator**, converta o texto
em curvas antes de enviar à gráfica, ou a fonte cai para uma serifa qualquer.
